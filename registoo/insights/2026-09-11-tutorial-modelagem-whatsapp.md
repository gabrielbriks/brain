# Tutorial de Modelagem: Clone do WhatsApp

Insight sobre a criação de tutoriais de modelagem baseados na arquitetura de aplicativos famosos para melhorar o aprendizado.

## Ideia principal
Buscar ideias em aplicativos super famosos para modelar e, com isso, melhorar a qualidade e o apelo dos nossos tutoriais. 

O primeiro caso de estudo sugerido é o **WhatsApp**.

## Referência
- **Vídeo (YouTube Shorts):** [Modelagem de Banco de Dados do WhatsApp](https://youtube.com/shorts/fGSqdbDVnok?si=7gn2vxDHaobBnwzu)

## Objetivos
- Aumentar o engajamento através de exemplos práticos do dia a dia.
- Facilitar a compreensão de conceitos complexos de modelagem usando um modelo mental que os usuários já dominam (ex: como funcionam mensagens, grupos e contatos).
- Criar uma série de conteúdos "Como modelar o app X".

## Próximos Passos
1. Analisar o vídeo de referência e extrair a estrutura de dados (Tabelas de Usuários, Conversas, Mensagens, etc).
2. Adaptar essa modelagem para o formato dos tutoriais do Registoo.
3. Criar um roteiro prático demonstrando o passo a passo da construção dessa estrutura.
4. Levantar outras ideias de apps famosos para os próximos tutoriais (ex: Instagram, Netflix, Uber).
