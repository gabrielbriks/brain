# Historuja

SaaS de histórias sociais para pessoas neurodivergentes. Ajuda cuidadores e terapeutas a criarem histórias visuais personalizadas para preparar neurodivergentes para situações do cotidiano.

## Subpastas
- `insights/` — Aprendizados e descobertas durante o desenvolvimento
- `issues/` — Bugs e problemas abertos
- `backlog/` — Features e melhorias planejadas
