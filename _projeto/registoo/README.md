# Registoo

PWA de registro de atendimentos domiciliares. Permite que profissionais de saúde (ex: cuidadores, enfermeiros) registrem visitas, evoluções e ocorrências diretamente pelo celular, sem depender de internet estável.

## Subpastas
- `insights/` — Aprendizados e descobertas durante o desenvolvimento
- `issues/` — Bugs e problemas abertos
- `backlog/` — Features e melhorias planejadas
- `decisions/` — Decisões técnicas e de produto (padrão ADR)
