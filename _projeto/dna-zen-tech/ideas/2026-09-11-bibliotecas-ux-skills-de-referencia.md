# Bibliotecas de UX Skills (Referência para o DNA Zen Tech)

## Principais opções de bibliotecas de UX Skills

| Projeto | Foco | Recursos principais | Licença / Instalação |
|---|---|---|---|
| **AI UX Playground (SKILL.md)** | UX design, acessibilidade, UX writing, design systems | +160 SKILL.md prontos para designers e PMs; inclui checklists de acessibilidade, geração de PRDs, especificação de componentes UI | Open-source, fácil instalação em Claude Code / Cursor |
| **Vibe Building Skills** | Produto + UX + frontend | 40 skills cobrindo estratégia de produto, revisões heurísticas de UI/UX, auditorias de usabilidade, acessibilidade, recomendações de experiência | MIT License, repositório GitHub ativo |
| **UI Skills (EveryDev.ai)** | UI/UX engenharia de design | Skills para polimento visual, acessibilidade, animações, workflows shadcn/ui, auditorias de React | Open-source, CLI (`npx ui-skills`) para instalação |

---

## 📌 O que cada um oferece de valor para UX

- **AI UX Playground**: ideal se você quer uma biblioteca ampla e modular, com *skills* que vão desde UX writing até auditorias de acessibilidade. É bem parecido em robustez com o Advertising Skills, mas voltado para design e experiência.
- **Vibe Building Skills**: combina UX com estratégia de produto e frontend. Se você busca algo que una **design + produto + marketing**, é uma opção completa.
- **UI Skills**: mais técnico, voltado para quem trabalha com **design engineering**. Excelente para auditar interfaces, melhorar animações e aplicar princípios de design em código.

---

## 🚨 Pontos de atenção para a Skill Zen Tech

- **Maturidade da comunidade**: Advertising Skills já tem bastante adoção em marketing. No caso de UX, o AI UX Playground e o UI Skills estão crescendo rápido, mas ainda são menos difundidos.
- **Integração com Claude Code / Antigravity**: todos funcionam via prompts estruturados (*SKILL.md* ou CLI), então a integração é simples e padronizada.
- **Escopo e Diferenciação do Zen Tech**: enquanto essas bibliotecas oferecem checklists genéricos de mercado, a nossa **Skill Zen Tech** deve integrar esses conhecimentos com os **padrões autorais** do nosso ecossistema (*Zen Sync*, *PermissionGuard*, *Bottom Drawers ergonômicos*, *URL-first State* e *Warm Minimalism*).
